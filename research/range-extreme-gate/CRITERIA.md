# 预登记评估标准（在查看任何结果前写定）

`.ai-memory/entry-gate-research.md` 记录了 7 个"看起来很好"后被推翻的候选门禁。
所以本次先把判定标准写死，再跑数。事后不得放宽。

## 主指标
`nret = (exit-entry)/entry * dir / atr_pct`
即 ATR 归一化收益。**不用 realized_pnl**：仓位大小/杠杆在样本内变化，
金额差异会把"仓位大"误当成"信号强"。

## 核心变量
`opp_atr` = 入场价到最近**逆向**结构区的距离（ATR 单位）
- LONG  -> 上方阻力
- SHORT -> 下方支撑
方向未签名的"最近区"不算（CLUSDT 与 SKHYNIX 会被打成同一分）。

## 通过门槛（全部满足才算成立）
1. **单调性**：opp_atr 分箱后 nret 必须单调，不能只有单个阈值突刺。
2. **位移安慰剂**：把 opp_atr 换成**同向**（保护侧）距离重跑，
   效应必须**消失**。若两边都"有效"，说明测到的是波动率而非几何。
3. **时间半分**：按 entry_time 中位数切两半，两半同号。
4. **样本量**：被拦区间 n >= 60，否则只报不启用。
5. **缩仓分支**：缩仓后必须按风险重归一化再比较，
   否则"少亏"只是因为下注少，不是决策变好。

## 预设结论路径
- 4 项全过 -> 实现门禁，默认 audit-only，参数可配 + 开关。
- 部分过 -> 只实现观测与 UI，不启用拦截。
- 安慰剂同样显著 -> 放弃，写入 memory 作为第 8 个被否候选。
