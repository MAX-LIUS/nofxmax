## 一句话结论

**决策时点的预测型门禁已经到顶, 不要再加。** 真正可动的杠杆是**几何与单位**, 
不是预测: 保本 arm 阈值必须改用 ATR 单位, 且应显著前移。

## 第八条候选详录: 区间极限位置门禁 (2026-08-04, 未实现)

来源: 用户依 CLUSDT LONG (id 1898) 与 SKHYNIXUSDT SHORT (id 1926) 两笔亏损, 要求
新增门禁拦"前高/前低/前前高/前前低/成交密集区"处的开仓, 并缩仓至 1/3。

数据: `research/range-extreme-gate/`, n=1759 已平仓单, 几何**从当时 prompt 原文解析**
(prompt 即因果记录, 规避 kline 重对齐的 70.7% 保真上限)。核心变量 `opp_atr` =
入场到最近**逆向**结构区距离 (ATR 单位; LONG→上方阻力, SHORT→下方支撑)。

**结论: 否决拦截。** 预登记 5 条判据 (`CRITERIA.md`) 全数未过:
- 单调性: 分箱中位数 +0.314/+0.343/+0.293/+0.247/+0.263 —— 平坦, 无梯度
- 安慰剂: 保护侧 `prot_atr` AUC 0.502 ≈ 逆向侧 0.514, 两侧同等无信息
- 时间半分: tight−wide 差 −0.088 / −0.091, **与假设反号**
- 缩仓分支风险重归一化后 `opp_atr<0.5` 单位风险均值 **+0.001** (不是负数)

**方向反转 (最重要)**: 按方向签名后 `adverse_pos>=0.75` (多头在顶/空头在底, 即用户
描述的"极限位置") n=893 中位 **+0.414 / 胜率 60.5%**, 而区间中部 n=830 中位 +0.207 /
54.8%。原因: 系统本质是趋势跟随 —— LONG 963 笔有 437 笔在区间上部, SHORT 796 笔有
456 笔在下部。**"极限位置"是系统的常态工作区, 也是它最赚钱的区**。拦掉等于拦掉主收益。
交易 1926 所属组合 (逆向 A 级区 <0.5x + 逆势极限) n=120 中位 +0.430 / 胜率 60.0% ——
它是 60% 胜率总体里的一笔正常亏损, 不是系统性缺陷。

**缩仓需求其实已满足**: 两笔被投诉的单子, `riskBasedPositionSize` 早已缩过仓 ——
SKHYNIX AI 要 100 → 实际 32.19 USDT (**0.32×**, 已比用户要求的 1/3 更狠);
CLUSDT AI 要 300 → 196.02 (0.65×)。机制是按 `effStop` 反算, 止损越宽仓位越小。

**CLUSDT 的真实缺陷与本门禁无关**: `opp_atr=2.44` (上方阻力 2.4×ATR, 空间充足),
它输在 ①逆势 (1h fib `direction=retracement_up`, 下跌结构里做回撤多)
②止损 1.05×ATR 被 `structural` 档 (`stop_loss_pct=3.2`, `backstop_atr_mul=3.1`)
放宽到 2.81×ATR —— 但这是**配置内的设计行为**, 且仓位已随之缩小, 不是 bug。

**另: 用户要的检查其实已存在但被关闭** —— `structural_blocking_level_too_close`
在 `entry_gate.go` 里已实现, 但两个实盘策略的 `structural_min_blocking_pct` 均为 **0**。
本轮数据说明: 保持为 0 是对的。

**三个自纪 (本轮修掉的真保真 bug)**:
1. 因果 join 反了一整个周期: 决策记录在开仓**后** ~10–12s 落库, 而周期 ~20min,
   "取入场前最后一条"必然取到上一周期。两笔手工核对单给出 0.752/2.300 而非真值
   0.438/2.500。改为"取 [入场−60s, 入场+300s] 内第一条", 并把 join 本身写进 selftest
   (只 pin 解析器不 pin join, 等于没 pin)。
2. `atr_price` 由 prompt 的 "x.x ATR" 反解, 而该值只有**一位小数**, 距离越近放大越狠 →
   出现 0.00%–0.2% 的不可能 ATR 和一笔 **343.7 ATR** 的假交易, 单笔就主导了整个分箱均值
   (bin 均值 +0.532, 截尾后只剩 +0.034)。改为只用 >=0.3x 的区反解并取**中位数**,
   ATR% 越界 (0.15%–20%) 直接弃样本。
3. 相关子查询逐笔扫全部大 prompt (1922×~20k), 两次 600s 超时零输出。改两阶段:
   先只建 (trader, created_at, id) 索引, 再按主键取 prompt → 13.5s。

## 第九条候选详录: 逆势过滤 (2026-08-04, 未实现)

来源: 用户追问"CLUSDT 逆势那个应不应该过滤"。CLUSDT LONG (1898) 的 1h
`fibonacci_context direction=retracement_up`, 即下跌结构里做多。

定义已核对源码 `market/fibonacci.go:57-68`: swing high 先于 swing low → 价格下行 →
retracement 向上, 故 **retracement_up = 下跌结构, LONG 为逆势**;
retracement_down = 上涨结构, SHORT 为逆势。`fib_dir` 已验证是**每币种一个值**
(同一 prompt 内 9 币出现两种取值), 不是全局行。覆盖 1760/1760。

预登记判据见 `CRITERIA_COUNTERTREND.md`。**结论: 否决拦截。**

判据逐条:
- [1] 效应量 **勉强过**: 逆势 n=645 中位 +0.236 / 胜率 55.7%, 顺势 n=1115 中位 +0.366 /
  58.7% → 中位差 −0.130 (门槛 ≤−0.10), 胜率差 −3.1pp (门槛 ≤−3pp)
- [2] 时间半分 **过但极弱**: 前半 −0.096 / 后半 −0.020
- [3] 样本量 过 (645 ≥ 100)
- [4] 分方向 **不过**: LONG 逆势中位差 −0.228 / 胜率 −5.1pp, 但 SHORT 逆势
  只有 −0.066 且**胜率反而 +0.8pp**。单边成立 → 按预登记路径转"只对 LONG 缩仓不拦截"
- [5] 控制 atr_pct 后仍在 (低波动 −0.095 / 高波动 −0.209)

转入 LONG 子集复检后**同样不成立**:
- 时间半分**反号**: 前半 −0.196 (n=261) → 后半 **+0.053** (n=132)
- bootstrap 95%CI **[−0.423, +0.024] 含 0**
- 逐月只有 2026-06 有效 (−0.155), 2026-05 −0.003 / 2026-07 −0.021 / 2026-08 **+0.390**

**用户的机制主张被直接否掉**: 原话"带概率会被打回反转"是**左尾**主张。
逆势多单 <−2ATR 大亏占比 **10.2%**, 顺势 **10.7%** —— 一样;
亏损单平均亏幅逆势 **−1.338**, 顺势 **−1.432** —— 逆势反而更小。
最差十分位差 −0.268 但时间半分反号 (−0.993 → +0.315), bootstrap CI 含 0。
(分交易员 3/3 同号是唯一通过项, 不足以救。)

**根因是 beta**: 逐月看下跌结构占比与方向收益 ——
2026-06 下跌结构 62.0% (最高), 当月 LONG 中位 +0.000 / SHORT **+0.302**;
2026-08 下跌结构 55.8%, LONG **+0.366** / SHORT **−0.842** (反号)。
"逆势多单"在本段样本里实际等于"**下跌月做多**", 与 `fib_dir` 标签本身无关。
要靠它赚钱等于要能预判月度方向, 而 AUC ~0.50 天花板已排除该能力。

**中位数与均值分野需记住**: 逆势多单中位 +0.116 但均值 −0.094 (常赢小、偶亏大)。
只看均值会误判为强效应 —— 判据 1 已因单笔 343.7 ATR 假交易踩过一次。

## 成立的结论

### 1. 保本 arm 阈值的单位是结构性缺陷 (最高优先级)

`store/strategy.go:1677` `BreakEvenStop{TriggerMode: profit_pct, TriggerValue: 3, OffsetPct: 0.1}`。
阈值按"入场价百分比"而非 ATR 计, 于是 `arm_ATR = trigger_pct / atr_pct`:

- 实盘 610 单 atr_pct: p10=0.558 / p50=1.021 / p90=1.797
- **同一份配置的实际 arm 距离有 3.2× 离散**: 波动大的币 0.56 ATR 就 arm, 安静的币要 1.79 ATR
- 默认 3% 下, 中位币需要 **2.94 ATR** 顺向才 arm; 而实盘亏损单平均只走到 **0.56 ATR**

给唯一确实有效的机制注入了纯噪声。修正方向: `TriggerUnit` 已支持 `atr` (见 `BreakEvenStopRule`), 
改用 ATR 单位即可, 属配置项而非新预测逻辑。

### 2. arm 前移在两个总体上同号 (20 季 + 实盘)

固定 stop, arm 从 0.60 → 0.30 ATR:
- **20 季历史 (原始 ATR 单位, 无分母)**: +0.0348 ~ +0.0407 ATR, 19–20/20 季, p=0.0000, 四种 stop 宽度全单调
- **实盘 539 单重放**: +0.0979 ATR, bootstrap 95%CI [+0.0186, +0.1801] 不含 0
- 机制: 亏损单伤害 −1.0639 → −0.4813 ATR (**砍掉 55%**); 盈利单 +0.5164 → +0.3482 (砍掉 33%)。
  亏损缩得比盈利快, 账本翻正: −0.0436 → **+0.0543 ATR**
- `never arm` = −0.4618 ATR, 印证保护栈本身是这个账本能活的原因

**必须同时记住的反面**: 按"实际暴露风险"归一后 arm 0.30 **更差** (−0.1419 vs −0.0954), 
因为它只暴露 0.508 ATR 而非 1.201 ATR。**它靠少担风险赢, 不靠选得准**。
研究总体是随机入场负期望 (任何减暴露都显得好), 实盘是正期望 (减暴露会减利润), 
两者可以反号 —— 实盘重放同号才是这条能用的依据。上线前需按名义风险重新标定仓位。

### 3. 止损加宽 = 摩擦工程, 不是预测

净 R 随 stop 单调改善至 ~4 ATR 后停止 (4→5 p=0.588, 6→8 p=0.868), gross R 呈 U 形峰在 4.0。
但分解显示 **87% 的净收益来自摩擦份额**, gross 增量单独不显著 (1.5→2.5 p=0.2517)。
且 8 ATR 处 77% 是超时退出, 宽端量的是 48 根时间止损而非止损本身。
实盘止损中位已 2.44 ATR (`full_sl` 达 4.17), 本就不在陡峭段, 加宽无空间。

### 4. 目标上限: 无期望增量, 6.4× 方差

超过 2.0 ATR 后期望不再改善 (1.0→2.0 p=0.0059; 之后 p=0.25–0.59), 
而季度 σ 从 0.0150 涨到 0.0462。封顶 2.0 的期望代价 −0.0078R **不显著 (p=0.41)**, 
换来方差 **6.42×** 下降。实盘 `MaxTargetATRMul=5.0` + `MinRiskRewardRatio=3.0` 正处高方差端。
